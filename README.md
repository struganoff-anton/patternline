# PatternLine ✂️

Бесплатный инструмент для изменения толщины векторных линий в PDF-лекалах (в том числе PDF из Grafis 12).

## Запуск локально

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
streamlit run app.py
```

## Публикация бесплатно

1. Создайте публичный репозиторий `patternline` на GitHub и загрузите файлы проекта.
2. Откройте https://share.streamlit.io/ и авторизуйтесь через GitHub.
3. Нажмите **Create app**, выберите репозиторий, ветку `main`, файл `app.py`.
4. Нажмите **Deploy**. Полученную ссылку можно отправлять пользователям.

## Что делает

- Изменяет PDF-оператор `w` (толщина векторного штриха), без растрирования.
- Поддерживает фиксированную толщину в мм и умножение исходной толщины.
- Сохраняет размер страниц и координаты векторных путей.
- Обрабатывает несколько загруженных PDF по отдельности.

## Ограничения

- Не меняет толщину контуров букв (текст), растровых линий и изображений.
- Обрабатывает Form XObjects, перечисленные страницей; inline-изображения пока не поддерживаются (сообщает об ошибке).
- Если в PDF есть clipping paths, нестандартные эффекты, цветные слои, проверьте результат вручную.
- Режим «умножить» не меняет неявную толщину линий без явного оператора `w`.
- Утолщение визуально расширяет штрих в обе стороны от его осевой линии; геометрия пути не меняется.

## Приватность

При размещении на Streamlit Community Cloud PDF обрабатываются сервером приложения. Для конфиденциальных лекал используйте локальный запуск.
